동작을 선택하면 단계별 전달 내용이 여기에 표시됩니다.
이 문서를 수정하는 방법 (JSON 한 곳만 고치면 됩니다)

모든 내용은 이 파일 안의 <script type="application/json" id="flow-data"> 블록에서 나옵니다. 그래픽·패널·하이라이트는 전부 그 JSON을 읽어서 그려지므로, 동작을 추가하려면 flows 배열에 항목 하나만 넣으면 됩니다. (외부 파일 fetch가 아니라 인라인이라서 file://로 더블클릭해 열어도 그대로 동작합니다.)

{
  "id": "새-동작-id",
  "group": "핵심 데이터 흐름",          // 사이드바 그룹. 새 이름을 쓰면 그룹이 새로 생김
  "title": "화면에 보일 동작 이름",
  "summary": "한 줄 설명",
  "steps": [
    {
      "from": "Screen",                 // nodes[].id 중 하나
      "to":   "DataService",            // from 과 같으면 '모듈 내부 처리'로 그려짐
      "fromSide": "right",              // 선택: top / right / bottom / left
      "toSide":   "left",               // 생략하면 장애물을 피해 자동 결정
      "call": "save(input)",            // 실제 호출되는 함수 시그니처
      "data": "무엇이 넘어가는지",
      "note": "주의점 (선택 · 노란 박스로 표시)"
    }
  ]
}

노드를 추가할 때는 nodes 배열에 { "id", "label", "desc", "layer", "file" }을 넣습니다. layer는 layers[].id 중 하나이며, 배열에 넣은 순서대로 세로로 배치됩니다.
